# 「重ねて三目」Webアプリ設計書

## 1. 企画概要

「重ねて三目」は、3×3の盤面に自分の駒を置き、縦・横・斜めのいずれかに3つ並べる対戦ゲームです。各プレイヤーは大・中・小の駒を2個ずつ持ち、盤面上の駒より大きい駒を重ねてマスを奪うことができます。通常の三目並べに「サイズの選択」と「盤面の反転」を加えた、先読みが楽しいゲームを目指します。

## 2. 対象環境と構成

- モダンブラウザーで動く、HTML・CSS・JavaScriptのみの静的Webアプリ
- ビルドツールや外部ライブラリーを必要としない
- `index.html` を静的ホスティング、またはローカルのWebサーバーで配信して利用
- 画面はデスクトップとモバイルの両方に対応

| ファイル | 役割 |
|---|---|
| `index.html` | セットアップ、ゲーム盤、駒置き場、ルール表示の画面構造 |
| `styles.css` | 配色、レイアウト、レスポンシブ表示、駒と盤面のスタイル |
| `app.js` | ルール判定、対局状態、画面更新、コンピューターの探索 |
| `design-spec.md` | 本設計書 |

## 3. ゲームルール

1. 先攻は「×」、後攻は「○」。各プレイヤーは大・中・小を各2個、合計6個持つ。
2. 1手ごとに、手番のプレイヤーは未使用の駒を1個選び、合法なマスに置く。
3. 空きマスにはいずれのサイズも置ける。駒があるマスには、現在見えている駒より大きい駒のみ置ける。
4. 重ねられた場合、上の駒だけが盤面上の駒として有効になる。下の駒は覆われたまま残り、使用済みとして戻らない。
5. 自分の駒が縦・横・斜めのいずれかに3つ並んだ時点で勝利する。勝利判定は各手の直後に行う。
6. 3つ並ばずに9マスすべてに駒が置かれた場合は引き分けとする。
7. どちらのプレイヤーにも合法手がなくなった場合は、盤面に空きマスがあっても引き分けとして対局を終了する。使用済みの駒は戻らないため、起こりうる終局である。
8. 「はじめから」で同じプレイヤー設定の新しい対局を開始できる。

## 4. 対戦モードと操作

- 対局前に、先攻・後攻それぞれを「プレイヤー」または「コンピューター」から選択する。
- プレイヤーの手番では、駒置き場からサイズを選び、ハイライトされたマスを選択する。
- 合法なマスを視覚的に示し、サイズが不足するマスには駒を置けないようにする。
- コンピューター同士の対局では、両者が自動で手を進める。
- 対局中は設定を固定し、対局終了後または再開始時に設定を変更できる。

## 5. コンピューターの方針

- 勝ち・負け・引き分けを終端とするミニマックス探索を行い、アルファ・ベータ枝刈りで不要な探索を省く。
- 自分が勝てる手を優先し、勝ちが保証できない局面では相手の勝ちを許さない手を選ぶ。
- 盤面上の駒、各プレイヤーの残り駒数、手番を探索状態に含め、同一状態をメモ化する。
- 盤面や残り駒が同じ局面は、それまでに覆われた駒の履歴に関わらず同一状態として扱う。合法手と勝敗は現在見えている駒および残り駒数だけで決まるためである。

## 6. 状態と判定

対局状態は、各マスの最上位の駒、マスに重なった駒の個数、プレイヤー別・サイズ別の残数、手番、手数で構成する。駒は所有者とサイズの組で表現する。各着手後に8本の勝利ラインを確認し、勝利がなければ盤面の充足と次の合法手を確認する。

## 7. 画面・アクセシビリティ

- 盤面を中心に、プレイヤー設定、現在の手番、残り駒、簡潔なルールを配置する。
- 先攻・後攻は色と「×」「○」の両方で区別する。
- 盤面はキーボードから操作できるボタンで構成し、マスの状態と駒選択を読み上げ可能にする。
- 対局状態をライブリージョンで通知し、勝利ラインを色でも強調する。
- 小画面では情報を縦方向に並べ替え、盤面の正方形比率を保つ。

## 8. 追加機能

- 対局のやり直し（選択した対戦方式は維持）
- 盤上で重なっている駒の数の表示
- 合法手のハイライトと、勝利ラインの強調
- コンピューター同士の自動対局
